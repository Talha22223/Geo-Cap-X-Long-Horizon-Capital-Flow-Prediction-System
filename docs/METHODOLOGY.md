# GEOCAP-X — System Methodology & Mathematical Specification

## 1. Data Classification Standard

GEOCAP-X strictly categorizes all intelligence data into four explicit tiers across the user interface and API layers:

1. **OBSERVED DATA (`data-layer-observed`)**: Directly ingested, unmanipulated raw source feeds (e.g., RSS news items, Yahoo Finance price bars, World Bank official macro series).
2. **DERIVED DATA (`data-layer-derived`)**: Calculated mathematical or NLP features computed strictly from observed data (e.g., spaCy NER entities, VADER sentiment scores, RSI/MACD technical indicators, NetworkX centrality scores).
3. **INFERRED DATA (`data-layer-inferred`)**: Algorithmic rules and heuristic projections generated by the Capital Flow Engine (e.g., $ USD Bn magnitude direction, multi-horizon directional shift).
4. **SCENARIO DATA (`data-layer-scenario`)**: Simulated counterfactual projections (e.g., Bullish/Bearish alternative scenarios, stress-tested horizon forecasts).

## 2. Intelligence Pipeline Architecture & Algorithms

### 2.1 Ingestion, Deduplication & Entity Extraction
- **Content Hashing**: SHA-256 fingerprint generated over title + normalized body to skip exact duplicates immediately.
- **Semantic Deduplication**: Composite weighted score evaluating title Jaccard similarity ($w_1 = 0.4$), body embedding distance ($w_2 = 0.4$), and publication timestamp delta ($w_3 = 0.2$). Threshold $\ge 0.80$ triggers candidate merging.
- **NLP Named Entity Recognition**: spaCy `en_core_web_sm` identifies GPE (countries), ORG (institutions), MONEY, and DATE entities. VADER sentiment computes normalized compound scores $[-1.0, +1.0]$.

### 2.2 Canonicalization & Cluster Resolution
Candidate events are grouped into `CanonicalEvent` entities using entity-overlap scoring and temporal window clustering ($\pm 48$ hours). Conflicting evidence (e.g., opposing sentiment across sources) is flagged explicitly (`has_conflicting_evidence = True`).

### 2.3 Causal Graph Network & Social Network Analysis (SNA)
Directed edges $E(u, v)$ represent temporal and semantic causal propagation:
$$\text{Weight}(u, v) = \alpha \cdot \text{EntityOverlap}(u, v) + \beta \cdot \exp(-\lambda \Delta t)$$

Calculated Centralities:
- **Degree Centrality**: Immediate connectivity and event influence.
- **Betweenness Centrality**: Identification of geopolitical "bridge events" mediating cross-border spillover.
- **PageRank Centrality**: Iterative stationary distribution modeling propagation flow across global markets:
$$PR(p_i) = \frac{1-d}{N} + d \sum_{p_j \in M(p_i)} \frac{PR(p_j)}{L(p_j)}$$

### 2.4 Statistical Abnormality Detection & Market Proxies
Market data anomaly is computed using rolling baseline Z-Scores:
$$Z = \frac{X - \mu_{30}}{\sigma_{30}}$$
- $|Z| > 2.0$: Significant market abnormality detected ($95.4\%$ confidence interval).
- $|Z| > 3.0$: Extreme capital flow shock detected ($99.7\%$ confidence interval).

### 2.5 Multi-Horizon Capital Flow Forecasting
Predictions project capital flow direction across four distinct temporal horizons:
1. **6-Month (6M)**: Immediate market reaction & short-term liquidity rotation.
2. **1-Year (1Y)**: Policy adjustment & trade balance realignments.
3. **3-Year (3Y)**: Structural capital reallocation & FDI shifting.
4. **5-Year (5Y)**: Long-term macroeconomic analog projection.

Forecast magnitude ($M_{USD}$) combines event severity ($S$), asset class volatility ($\sigma$), and network centrality ($C_{PR}$):
$$M_{USD} = S \times (1 + C_{PR}) \times \text{BaseMultiplier}$$

## 3. Historical Backtesting & Calibration

The validation engine (`apps/ai/capital_flow/backtest.py`) prevents lookahead bias through **Point-in-Time Temporal Snapshots**:
1. At historical timestamp $T_0$, the system filters out all events and market data where $t > T_0$.
2. The engine executes full inference strictly on historical data $t \le T_0$.
3. The resulting forecast is evaluated against actual market observations at $T_0 + H$ (where $H \in \{6M, 1Y, 3Y, 5Y\}$).
4. Directional Accuracy, Brier Score, and Calibration Error are computed to quantify model reliability honestly.
